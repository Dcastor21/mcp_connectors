# Specs

One folder per PRD feature: `f<nn>-<slug>/` with `spec.md` (what), `design.md` (how), `tasks.md` (the build plan) and, once verified, `traceability.md` (requirement → test evidence).

Run `python3 scripts/sdd.py status` for the current board. The workflow is in [docs/spec-driven-development.md](../docs/spec-driven-development.md).
